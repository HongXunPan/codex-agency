# codex-agency

这是 Codex Agency 的 shared 层数据仓库。

## 作用

- 存放可跨设备同步的长期资产
- 存放人格骨架、策略人格、已批准记忆、路线图与角色定义
- 不存放本机 runtime、原始反馈、pending/trial 等临时态数据

## 目录

- `config/`：共享配置
- `identity/`：核心人格、策略人格、治理规则
- `memory/approved/`：全局长期记忆
- `projects/`：项目级长期资产
- `roadmap/`：路线图与演进日志
- `roles/`：领域角色与阶段角色

## 说明

本仓库由全局 Codex Agency 维护。
